# Knowledge Hub AI

Yabancı dildeki teknik içerikleri Türkçe okumak ve dinlemek için kişisel bilgi kütüphanesi.

İlk hedef: kaynak metin veya izinli ses dosyası → teknik çeviri → doğrulama → Türkçe seslendirme.

Geliştirme ayrı dallarda yürütülür. API anahtarları ve telifli kaynak içerikleri repoya eklenmez.
