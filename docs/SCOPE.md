# Product scope
Personal, Turkish-first reader and listener for authorized multilingual technical content.
P0: local CLI, text ingestion, faithful translation, optional MP3, provenance and tests.
P1: authorized article URL extraction with SSRF protections; audio transcription with timestamps and speaker labels; RSS discovery.
P2: bilingual reader, library, playback position, mobile interface.
P3: optional explanatory and summary modes, explicitly separate from translation.
Quality gates: no omitted paragraphs, preserve equations, numbers, code and technical terminology; human-reviewed bilingual benchmark; record model, latency and cost. Automated checks are not proof of semantic fidelity.
No automatic paid processing, public redistribution, voice cloning, or bypass of access restrictions. Keep user content outside Git. Provider choices remain configurable.
